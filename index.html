This browser can't use Bluetooth

On iPhone, Safari and Chrome don't allow web pages to connect over Bluetooth. Use the free Bluefy browser instead:

  1. Install Bluefy – Web BLE Browser from the App Store.
  2. Open this same page in Bluefy.
  3. Fully close the Anker app first (it holds the Bluetooth connection).

Tips
  • Close the Anker app completely before connecting. The bank only talks to one phone app at a time.
  • If it won't show up, press the bank's button once to wake Bluetooth.
  • Keep this page open on screen. iOS pauses Bluetooth for backgrounded pages; the screen is kept awake while connected.
  • The estimate averages the power draw over the last 3 minutes (a real change, like unplugging a laptop, is picked up in about 30 seconds), and it learns your bank's real capacity as the battery drains.
